# Pinboard

Скачивание досок и отдельных пинов Pinterest. Windows 10/11 x64.

## Запуск

1. Скачайте `Pinboard-1.1.0-Windows.zip` из **Releases**.
2. Распакуйте и запустите `Pinboard.exe`.
3. Вставьте ссылку → **Скачать**.

Python не нужен. Интерфейс откроется в браузере. Файлы — в папке `downloads`; путь меняется в настройках.

## Из исходников

Установите Python 3.10+, скачайте **Code → Download ZIP**, распакуйте и запустите `Start Pinboard.cmd`.
